# PocketTracker — Gumroad Listing Draft

## Product title
PocketTracker — Private Offline Personal Finance Tracker

## Short description
A clean, responsive personal finance tracker built with plain HTML, CSS and JavaScript. Track income, expenses, budgets and cash flow without accounts, servers or API keys.

## What buyers get
- Complete HTML/CSS/JavaScript source
- Responsive dashboard
- Add, edit and delete transactions
- Search and income/expense filters
- Monthly category budgets
- Monthly cash-flow reports
- CSV export
- JSON backup and restore
- NGN, USD, GBP and EUR display options
- Dark/light mode
- PWA manifest and service worker
- Customization guide
- Commercial-source license template
- Changelog

## Key selling points
- No npm or build process
- No backend required
- No API key required
- Local browser storage
- Easy to customize
- Suitable for static hosting
- Works as a web app and can be installable in supported browsers

## Important buyer note
PocketTracker stores financial data locally in the user's browser. It does not synchronize data between devices and does not provide cloud backup. Buyers should use the built-in JSON backup feature when moving or protecting their data.

The "Mark as monthly" option is a label only; it does not automatically generate future transactions.

## Suggested product format
Deliver a ZIP containing the complete tested source and documentation.

## Suggested support policy
Support can cover installation and source-code questions. Ongoing hosting, custom development, data recovery, and third-party browser issues should be excluded unless explicitly offered.

## Suggested FAQ

### Does it need a server?
No. The core application is static.

### Does it need an API key?
No.

### Does it require a database?
No. Data is stored locally in the browser.

### Can I customize the branding?
Yes. The customization guide explains the main files and CSS variables.

### Can I use it commercially?
Use the included license terms as the starting point, and review or replace them for the exact rights you intend to grant.

### Does it automatically repeat monthly transactions?
No. Monthly is a label, intentionally. This prevents accidental duplicate financial records.
